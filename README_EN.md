# MECHREVO BIOS / EC Firmware Archive

[简体中文](README.md) | [English](README_EN.md)

This is a community-maintained archive of MECHREVO BIOS / EC firmware. It collects official firmware download links and firmware files to make them easier to find.

> [!WARNING]
> **Flashing BIOS / EC firmware carries a risk of making the device unbootable.** Confirm that the firmware matches your model and keep the device on stable power throughout the update.

## Submit BIOS / EC Firmware

You are welcome to share firmware leads in [Discussions](https://github.com/YYplus/Mechrevo-BIOS/discussions). **All we need is the MECHREVO model name and either a BIOS / EC firmware download link or the firmware file itself.** Other details are optional.
