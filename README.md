# 机械革命 BIOS / EC 固件归档

[简体中文](README.md) | [English](README_EN.md)

这是一个由社区维护的机械革命（MECHREVO）BIOS / EC 固件归档项目，用于收集和整理各机型的官方固件下载链接及固件文件，方便用户查找。

> [!WARNING]
> **刷写 BIOS / EC 存在导致设备无法启动的风险。** 请确认固件适用机型，并确保更新过程中设备保持稳定供电。
