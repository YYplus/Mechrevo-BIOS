# 机械革命 BIOS / EC 固件归档

[简体中文](README.md) | [English](README_EN.md)

这是一个由社区维护的 **机械革命（MECHREVO）BIOS / EC 固件归档仓库**，按机型或 BIOS 平台整理官方固件、下载来源和相关版本信息。

> [!WARNING]
> **刷写 BIOS / EC 存在导致设备无法启动的风险。**
>
> 请确认机型、固件版本及对应平台后再进行更新，并确保更新过程中设备保持稳定供电。

## BIOS 更新注意事项

以下注意事项和更新步骤整理自机械革命客服提供的说明。

1. 更新 BIOS 固件版本可能会触发 BitLocker 密钥验证。请在操作前确认并牢记当前 Windows 登录所使用的 Microsoft 账户信息；也可以在更新前关闭“设备加密”。Windows 11 可进入 **开始菜单 → 设置 → 隐私和安全性 → 设备加密** 进行关闭，也可以直接在系统搜索框中搜索“设备加密”。
2. 运行 BIOS 更新文件前，请先退出第三方管家、安全防护等软件，避免出现冲突或拦截。

## BIOS 更新步骤

1. 如下载的是压缩包，请先右击并选择**全部解压缩**；如下载的已经是 `.EXE` BIOS 更新程序，可直接进行下一步。
2. 确认电脑已连接电源适配器，然后右击 BIOS 更新应用程序，选择**以管理员身份运行**。
3. 等待运行窗口中的进度完成后，按提示输入字母 **Y**，确认重启。
4. 电脑会自动重启并完成 BIOS 更新。更新过程中请勿操作键盘、鼠标，也不要断开电源，等待电脑自动完成更新并重新进入 Windows 系统。

## 仓库结构

```text
models/
└─ <机型或平台>/
   ├─ README.md
   ├─ README_EN.md
   ├─ manifest.yaml
   └─ firmware/
      └─ <官方固件文件>
```

每个条目保存机型/平台信息、BIOS/EC 版本、机械革命官方下载地址（如已知）以及对应的固件文件。

## 固件文件

BIOS / EC 固件统一保存在各条目的 `firmware/` 目录中，并保留机械革命原始文件名。若官方来源地址已知，同时记录在对应条目中。

新增固件时，请保留厂商原始文件名，不对文件内容进行修改。

## 提交新的 BIOS / EC 信息

可以通过仓库 Issues 提交新的固件线索。建议提供：

- 机械革命具体机型；
- BIOS / EC 版本；
- 官方下载地址（如有）；
- 原始文件名；
- 适用年份或平台；
- 已知的 EC 配套信息。
