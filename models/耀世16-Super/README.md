## 实测与反馈

- @Icather [实测反馈](https://github.com/YYplus/Mechrevo-BIOS/issues/3#issuecomment-7189742406)：`GM6IX8B` / ROM ID `GMxIX9xN` 已实刷 `N.1.10MRO09`，该设备尚未实测 `N.1.11MRO10`。
- 毁灭者（i9-14900HX + RTX 4080）：用户反馈客服固件解决狂暴模式蓝屏重启，原帖版本与文件名不一致。
