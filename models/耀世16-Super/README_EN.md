## User reports

- @Icather [test report](https://github.com/YYplus/Mechrevo-BIOS/issues/3#issuecomment-7189742406): `GM6IX8B` / ROM ID `GMxIX9xN` successfully flashed `N.1.10MRO09`; `N.1.11MRO10` not yet tested on that unit.
- Destroyer variant (i9-14900HX + RTX 4080): a customer-support update reportedly resolved blue-screen restarts in performance mode; reported version differs from the filename.
