## 实测与反馈

- `MRID6_23_V40`：更新后首次重启可能较慢（用户反馈）。
- `N.1.49MRO58`：@Blackstone234 提供控制中心推送记录（[Issue #1](https://github.com/YYplus/Mechrevo-BIOS/issues/1#issuecomment-6741848173)）。
