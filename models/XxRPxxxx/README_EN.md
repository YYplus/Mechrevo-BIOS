## Known information

- MECHREVO has official product and support pages for the JIGUANG X Pro.
- A user reported that MECHREVO customer support provided `XxRPxxxxN135MRO58_CAP.zip` after the user requested a BIOS for a **JIGUANG X Pro**. This is a user-reported customer-support record and is retained as a model-association clue; it is not treated as an official published BIOS compatibility list.
- The firmware's internal series identifier is `KUANGSHI-JIGUANG Series-X6xx55xW-B2`. The repository therefore continues to archive it primarily by the `XxRPxxxx` platform and does not infer compatibility with every KUANGSHI / JIGUANG model.

The package was previously analyzed as an AMI UCP executable:

- File size: `10,729,168 bytes`
- `@UAF` offset: `0x119600`
- `@CMD` offset: `0x11EF90`
- `@ROM` offset: `0x11EFC0`
- Original AFU arguments: `/p /b /n /r /x /capsule`
- The BIOS contains the 800 × 600, 60-frame MECHREVO boot animation resource.
