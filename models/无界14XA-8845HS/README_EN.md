## Known information

- This BIOS download URL was supplied by MECHREVO online customer service. Its official directory is `MECHREVO2024/WJ14X8845HS/`.
- `GXxHXxx` is the official filename prefix; the actual motherboard identifier has not been confirmed.
- This entry covers the known **Ryzen 7 8845HS** variant only; it does not establish BIOS compatibility with the Intel Core Ultra 7 155H Wujie 14X.
- The original `N.1.14MRO50` EXE is archived in this model's `firmware/` directory; file size: 9,843,216 bytes.
- Thanks to @baby170303 for contributing the `N.1.15MRO27` firmware URL for Wujie 14X (2024, Ryzen 7 8845HS) in [Issue #8](https://github.com/YYplus/Mechrevo-BIOS/issues/8). The new URL uses the `BIOS/HPT_QB4/` directory. The original binary is archived (10,631,040 bytes); the precise target variants and cross-flash compatibility of the two versions remain unverified.
