## 已知信息

- 该 BIOS 链接由机械革命在线客服提供，官方目录为 `MECHREVO2024/WJ14X8845HS/`。
- `GXxHXxx` 是官方文件名前缀，不应直接视为已核实的主板标识。
- 本条目仅适用于已知的 **Ryzen 7 8845HS** 版本，不能据此认定 Intel Core Ultra 7 155H 的无界 14X 使用相同 BIOS。
- `N.1.14MRO50` 原始 EXE 已归档于本目录的 `firmware/`，文件大小为 9,843,216 字节。
- 感谢 @baby170303 在 [Issue #8](https://github.com/YYplus/Mechrevo-BIOS/issues/8) 补充无界 14X（2024，Ryzen 7 8845HS）的 `N.1.15MRO27` 固件及官方下载链接。新链接目录为 `BIOS/HPT_QB4/`，原始固件已归档，文件大小为 10,631,040 字节；两版固件的具体适用范围及互刷兼容性未核实。
